# 🌌 Cosmic-SPA: Interactive Space-Time Orbit Lab

A responsive, multi-page React Single Page Application (SPA) built for the **Front End Engineering-II (25CSE0203)** evaluation.

## 🚀 Key Features (Syllabus Aligned)
* **Cinematic Responsive Design:** HTML5 semantic tags with CSS Grid & custom keyframe animations simulating the "Space-Time Fabric".
* **Dynamic Orbital Routing:** Managed navigation utilizing `react-router-dom` incorporating dynamic parameters (`/planets/:id`), nested states, and custom "Lost in Space" 404 views.
* **Gravity Sandbox Lab:** High-performance real-time weight-force calculation engine leveraging React `useMemo` and physical parameters.
* **NASA Command Center:** Secure protected route utilizing `localStorage` to view telemetries.

## 🛠️ Tech Stack Constraints
* **Frontend Framework:** React (Vite environment)
* **Routing Engine:** React Router v6
* **Styling Architecture:** Tailwind CSS / Native CSS Grid & Flexbox
* **State Management:** Native Hooks (`useState`, `useEffect`, `useRef`, `useMemo`)
